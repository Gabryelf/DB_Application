# Цифровая Академия — База данных (Спринт 1: Таблицы)

## 🎯 Что это за проект
Мы создаём базу данных для учебного заведения «Цифровая Академия»: ученики, учителя, предметы, группы, расписание, оценки и связанные сущности.  
В этом спринте каждый студент создаёт **одну таблицу** (SQL-скрипт для MySQL) в своей персональной папке.

## 💬 С чего начать (обязательно прочитайте)
1. **[Wiki: Старт](ссылка)** — правила, роадмап спринтов, как всё устроено.
2. **[Wiki: Схема сущностей](ссылка)** — общая карта таблиц и связей. Найдите свою сущность.
3. **[Issues](../../issues?q=label%3Asprint-1)** — найдите issue с вашим именем. Там задание и чекбоксы.
4. **[Projects: Kanban](../../projects/1)** — перетащите свою карточку в `In Progress`, когда начнёте, и в `Done`, когда закончите.
5. **Ваша папка:** `database/scripts/entities/<ваш-логин>/` — здесь вы создаёте файл `create_table.sql`.

## 📁 Структура репозитория
- `database/scripts/entities/<логин>/` — персональные SQL-скрипты таблиц.
- `database/scripts/` — будущие процедуры/триггеры (появятся в следующих спринтах).

## ✅ Требования к работе
- Только MySQL.
- Таблица должна иметь первичный ключ.
- Внешние ключи — если ваша сущность ссылается на другую.
- Комментарии в SQL: краткое назначение таблицы и полей.
- Файл: `database/scripts/entities/<ваш-логин>/create_table.sql`.

## 🆘 Если что-то непонятно
- Смотрите Wiki-страницу вашей сущности (ссылка есть в вашем Issue).
- Задавайте вопросы в **Discussions** (раздел Q&A).
